# SplitEasy

App web per dividere le spese
Progetto di studio

## Tecnologie

- Backend: Node.js, Express, TypeScript
- Forntend: React, Vite, TypeScript
- Database: PostgreSQL

## COme avviare il backend

```bash
cd backend
nmp install
npm run dev
```

Il server risponde su http://localhost:3000/health

## Come avviare il frontend

```bash
cd frontend
npm install
npm run dev
```

La pagina si apre su http://localhost:5173

## Stato del progetto

Settimana 1 completata: backend e frontend di base. Prossimi passi: database, login, gruppi e spese.
